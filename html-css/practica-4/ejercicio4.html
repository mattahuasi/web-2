Módulo de diseño de cuadrícula CSS

Hasta ahora hemos visto como definir cuadrículas Grid CSS donde definimos sus filas y sus columnas a través de propiedades como grid-template-rows y grid-template-columns
Sin embargo, no es la única forma de definir cuadrículas en CSS
Si necesitamos un poco más de flexibilidad a la hora de definir un grid, podemos utilizar una funcionalidad denominada Grid por áreas
que permite de forma casi gráfica y visual, definir mediante texto la ubicación y forma que van a tener las celdas de nuestra cuadrícula.
Este diseño de cuadrícula contiene seis columnas y tres filas.
